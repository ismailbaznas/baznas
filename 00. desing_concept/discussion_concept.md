# BAZNAS BOVEN DIGOEL

## MASTER VISUAL BLUEPRINT v1.0

### Bagian II — Spatial & UI Precision

Saya akan jadikan prinsipnya:

> **Tidak ada elemen yang “kebetulan” berada di suatu tempat.**

Semua punya alasan.

---

# 01 — CANVAS

Saya ingin website terasa **lega**, tetapi bukan kosong.

Untuk desktop:

### Max content width

**1280–1320 px**

Jangan full-width untuk seluruh konten.

Contoh:

```text
|----------------------- 1440px -----------------------|

        |--------- 1280px CONTENT ---------|

             margin ±80px kiri/kanan
```

Ini penting.

Website pemerintah sering salah di sini:

> layar 1920 → konten ikut melebar sampai 1800.

Akibatnya:

**mata capek + desain kehilangan fokus.**

BAZNAS kita harus terasa seperti **majalah institusi**, bukan dashboard.

---

# 02 — GRID

Gunakan grid yang konsisten.

### Desktop

**12-column grid**

dengan:

* gap: ±24 px
* container: 1280 px
* section padding horizontal: 32–48 px
* section vertical spacing: 96–120 px

Tetapi jangan semuanya matematis kaku.

Ada pengecualian untuk:

* Hero
* foto storytelling
* CTA
* footer

Karena section tersebut boleh "pecah" dari grid.

---

# 03 — ATURAN "KURANG KANAN SEDIKIT"

### Optical alignment > mathematical alignment

Kalau secara matematika:

> x = 80

tetapi mata merasa:

> x = 72

**pakai 72.**

Ini yang dimaksud:

> "kurang kanan sedikit."

# 05 — HERO IMAGE

Jangan sampai foto mengambil perhatian lebih besar daripada headline.

Rasio visual kira-kira:

```text
TEXT              FOTO
40%                60%
```

Tetapi objek manusia jangan ditempatkan tepat di tengah.

Ideal:

```text
[ TEXT ]          [      👦
                   FOTO ]
```

Subjek foto berada sekitar:

**65–75% dari lebar hero.**

Dengan begitu mata:

**headline → wajah → CTA**

secara natural.

---

# 06 — HERO HEIGHT

Jangan terlalu tinggi.

Desktop:

**600–680 px**

Bukan:

> 900 px cinematic hero.

Karena website layanan harus memberi sinyal:

> **"Di bawah ini masih ada sesuatu."**

Begitu hero selesai, bagian berikutnya **sedikit terlihat**.

Ini disebut *peek*.

Pengunjung secara psikologis terdorong scroll.

---

# 07 — STATISTICS

Ini yang tadi dalam gambar menurut saya masih terlalu "dashboard".

Kita perlu mengubahnya menjadi:

### TRUST STRIP

Bukan card.

Jangan:

```text
┌────────┐ ┌────────┐ ┌────────┐
│ Rp 0   │ │ 0      │ │ 0      │
└────────┘ └────────┘ └────────┘
```

Lebih seperti:

```text
Rp X.X M        XXX           XXX          XX
Dana ZIS       Muzaki       Mustahik     Program
```

Satu garis horizontal.

Tidak perlu border masing-masing.

**Ini membuat website terasa lebih premium.**

---

> putih → putih → putih → putih.

Jadi website memiliki **tempo visual**.

Seperti layout majalah.

# 09 — PILAR PENYALURAN

Ini saya ingin **lebih tenang** daripada gambar pertama.

Lima card jangan terlalu ramai.

Icon:

**24–32 px**

**20–22 px**

Deskripsi:

**14–15 px**

**190–220 px**

* icon gold

**white + subtle border + green icon.**

Gold hanya muncul ketika hover/active.

---

# 10 — WHITESPACE

Ini bagian yang sering membuat orang panik:

> "Kok kosong?"

**Biarkan kosong.**

Whitespace bukan ruang terbuang.

Ia membuat:

> **informasi penting terlihat penting.**

Saya ingin:

### Heading section

± **48 px**

kemudian:

**20–24 px**

baru body/card.

Bukan:

```text
HEADING

          ↓ 70px

BODY
```

terlalu renggang.

Dan jangan:

```text
HEADING
↓ 8px
BODY
```

terlalu dempet.

Targetnya:

> **rapat secara intelektual, lega secara visual.**

---

# 12 — ANGKA

---

# 14 — FOTO

Ini salah satu perubahan terbesar yang akan saya rekomendasikan.

**Jangan gunakan terlalu banyak foto yang terlihat seperti AI.**

Karena sekarang orang sudah sangat sensitif terhadap:

> kulit terlalu sempurna
> tangan aneh
> ekspresi generik
> lighting cinematic berlebihan.

Untuk BAZNAS:

### dokumentasi nyata > foto sempurna.

Bahkan foto yang sedikit tidak sempurna **lebih dipercaya**.

Foto:

> blur sedikit
> cahaya kurang sempurna
> lingkungan nyata

justru bisa memberikan:

**AUTHENTICITY.**

# 18 — RADIUS

---

# 19 — SHADOW

**Sangat sedikit.**

Kalau card harus terlihat karena:

> shadow 0 20px 40px...

berarti kemungkinan layout-nya salah.

Lebih baik:

```text
border: subtle
background: white
shadow: minimal
```

Trust lebih dekat dengan **stability** daripada "floating UI".
