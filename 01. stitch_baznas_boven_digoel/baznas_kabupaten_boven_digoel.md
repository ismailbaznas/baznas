# BAZNAS KABUPATEN BOVEN DIGOEL
## WEBSITE — VISUAL DESIGN SPECIFICATION v1.0

### DESIGN REFERENCE

Use the attached homepage concept image as the primary visual reference for the overall art direction, composition, visual hierarchy, proportions, typography character, spacing rhythm, color balance, and institutional feeling.

IMPORTANT:
- Do NOT reproduce the reference image literally.
- Do NOT copy its placeholder data, names, numbers, bank accounts, contact information, or fictional content.
- The reference image represents the intended visual "spirit" and design language.
- Adapt the design into a realistic, production-ready BAZNAS Kabupaten Boven Digoel website.
- All current website content/data should remain structurally compatible with the existing project.

---

# 1. CORE DESIGN PHILOSOPHY

The website must communicate:

**PROFESSIONAL → OFFICIAL → TRANSPARENT → HUMAN → TRUSTWORTHY → ACTION**

The design should follow this psychological sequence:

**LOOK → READ → BELIEVE → ACT**

The visitor is already physically close to the website, unlike a roadside billboard. Therefore, the design must first establish visual credibility, then provide clarity, then prove trustworthiness, and finally encourage action.

The website should feel like:

> A professional Islamic philanthropic institution with strong government/institutional credibility, modern editorial design, transparent financial communication, and a genuine connection to the people of Boven Digoel.

It should NOT feel like:

- a generic government template
- a generic Islamic website
- a fintech startup
- a charity landing-page template
- an overly decorative Islamic website
- an AI-generated design
- a dashboard disguised as a public website

- headings where appropriate

Typography must create a clear distinction between editorial headings and functional body text.

### Display / Heading Font

Use an elegant editorial serif similar in character to:

**Playfair Display**

Use for:
- hero headline
- major section headings
- important storytelling headlines

Characteristics:
- large
- elegant
- confident
- high contrast
- editorial

### Body / UI Font

Use a clean modern sans-serif similar to:

**Plus Jakarta Sans**

Use for:
- navigation
- body copy
- buttons
- labels
- metadata
- statistics
- forms
- cards

Do not use too many font families.

Maximum:
**2 font families.**

Approximately:

Approximately:

---

# 6. LAYOUT SYSTEM

Desktop content should use a centered container.

Recommended:

**max-width: 1280–1320 px**

Do not stretch text and cards across the entire screen on large monitors.

Use a consistent 12-column grid.

Recommended desktop spacing:

- grid gap: approximately 24 px
- horizontal content padding: 32–48 px
- major section vertical spacing: approximately 96–120 px

The design should feel spacious but not empty.

Principle:

> "Rapat secara intelektual, lega secara visual."

Whitespace is intentional.

---

# 7. OPTICAL ALIGNMENT

Do not rely exclusively on mathematical centering.

Use **optical alignment**.

When a composition contains:
- large typography
- photographs
- statistics
- buttons

the visual weight should determine positioning.

If an element mathematically centered feels visually off-center, adjust it optically.

The final result should feel balanced to the human eye.

- easily recognizable

# 22. PHOTOGRAPHY DIRECTION

Photography is extremely important to the brand.

Priority:

**Authenticity > Perfection**

Preferred:

- real people
- real locations
- real activities
- natural expressions
- documentary composition
- local context

Avoid:

- generic corporate stock photos
- overly staged charity photos
- exaggerated emotional imagery
- obviously AI-generated humans
- excessive cinematic effects

Boven Digoel should be visible through real visual storytelling.

The local identity should feel natural, not like a decorative "Papua theme".

Mobile is not merely a collapsed desktop layout.

Design mobile intentionally.

Mobile hierarchy:

1. Logo + navigation
2. Hero
3. Primary CTA
4. Trust statistics
5. Five pillars
6. Transparency
7. Impact story
8. News
9. Final CTA
10. Footer

Hero headline:

approximately:
**40–48 px**

Maintain strong whitespace.

Cards can become vertical or horizontally scrollable where appropriate.

Buttons must remain easy to tap.

---

# 24. MOTION

Use restrained motion.

Preferred:

- subtle fade
- subtle upward translation
- small hover movement
- smooth transitions

Approximate animation duration:

**400–600 ms**

Avoid:

- excessive parallax
- spinning elements
- bouncing icons
- text flying in from every direction
- constant animated backgrounds
- excessive counters
- distracting effects

The emotional character should be:

**calm + stable + trustworthy**

---

# 25. ACCESSIBILITY & CONTRAST

Visual beauty must never reduce readability.

Prioritize:

- high text/background contrast
- readable font sizes
- clear CTA hierarchy
- visible focus states
- sufficient spacing
- accessible interactive elements

Never place light text over a bright photograph without sufficient contrast treatment.

Never sacrifice readability for aesthetics.

---

# 26. ANTI-AI-DESIGN RULES

This is critical.

DO NOT automatically add:

- gradients everywhere
- glassmorphism
- excessive gold
- excessive green
- huge rounded cards
- excessive shadows
- excessive icons
- excessive badges
- excessive animations
- decorative Islamic patterns everywhere
- generic stock photos
- unnecessary dashboard components
- oversized headings without purpose
- multiple CTA buttons competing with each other
- unnecessary sections
- excessive visual effects

Do not redesign the information architecture simply to make the interface look more impressive.

**Clarity and trust are more important than novelty.**

---

# 27. DESIGN PRIORITY

When making design decisions, follow this order:

### 1. TRUST
Does this look credible?

### 2. HIERARCHY
Does the visitor immediately know what matters?

### 3. READABILITY
Can the information be understood quickly?

### 4. AUTHENTICITY
Does it feel like Boven Digoel rather than a generic template?

### 5. BEAUTY
Does it look refined and modern?

### 6. INTERACTION
Does it encourage the correct action?

Never reverse this order.

---

# 28. FINAL VISUAL TEST

Before considering the design complete, evaluate the homepage at:

### 3 seconds

Can the visitor understand:

**This is BAZNAS Kabupaten Boven Digoel.**

### 10 seconds

Can the visitor understand:

**What BAZNAS does and why it matters.**

### 30 seconds

Can the visitor find:

**Programs + transparency + services.**

### 60 seconds

Can the visitor answer:

**"Why should I trust this institution?"**

### Final question

Would a first-time visitor feel comfortable clicking:

**Tunaikan Zakat**

?

If not, improve the design before adding more features.

---

# 29. IMPORTANT IMPLEMENTATION PRINCIPLE

Do not treat the reference image as a pixel-perfect target.

Treat it as a **visual north star**.

Preserve its:

- visual hierarchy
- calm institutional tone
- green/neutral balance
- restrained gold accent
- editorial typography
- generous whitespace
- photography-first storytelling
- transparency emphasis
- clear CTA hierarchy

But improve details where necessary for actual usability, responsive behavior, accessibility, and real content.

The final result should feel like:

# "BAZNAS Kabupaten Boven Digoel"

not:

# "AI-generated BAZNAS website template."

The design should be distinctive enough to feel intentionally art-directed, while remaining professional enough to represent an official public institution.
